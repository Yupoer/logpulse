Request flow

Client ── POST /logs ──> LogPulse API ──> Kafka
  │                         │              │
  ├─ GET /logs/:id          └─ Redis       ├─ consumer batch
  ├─ GET /logs/search ────────────────> ES  └─ MySQL + ES
  └─ GET /metrics ───────────────> Prometheus ─> Grafana

API 與 consumer 是同一個 process 的兩條 goroutine 路徑；Kubernetes 只對 app 做水平擴展，Kafka consumer group 會分配 partitions。
